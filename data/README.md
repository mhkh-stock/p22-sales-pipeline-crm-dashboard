# P22 — Data dictionary + known quirks

## The deals file — `data/raw/deals_SAMPLE.csv`

SAMPLE sales pipeline for the fictional Pakistani software company
**CitySoft Solutions**, Thu 2026-01-01 → Tue 2026-06-30 (6 months,
181 days). 156 deals, PKR 117,175,000 total pipeline, 40 won
(34.78% of 115 closed), PKR 26,135,000 revenue won, 41 deals still
open (PKR 31,925,000, weighted PKR 16,441,250). Generated by
`src/generate_data.py` (seed 20261118) with deliberately different
behaviour per rep (Ayesha Khan wins most often per deal, Daniyal
Raza least), per product line (ERP Implementation is biggest and
hardest to win, Website Development easiest), per source
(Referral closes best, Cold Outreach worst) and per stage (the
Negotiation → Won step is the biggest leak at 51.95%) — so the
report has a real funnel story, a real rep story and a real
forecast story to surface.

| Column | Type | Meaning |
|---|---|---|
| deal_id | text | `DL-0001` … `DL-0156`; the deal key |
| created_date | text | `yyyy-mm-dd`; the day the deal entered the pipe |
| month | text | `yyyy-mm`; the report's month key (created month) |
| close_date | text | `yyyy-mm-dd`; empty for open deals; the day the deal closed Won or Lost |
| expected_close_date | text | `yyyy-mm-dd`; open deals only; the month it feeds is the forecast month |
| rep | text | One of 6 sales reps |
| product_line | text | One of 5: ERP Implementation, Cloud Migration, Mobile App, Website Development, Digital Marketing |
| source | text | One of 4: Referral, Website, LinkedIn, Cold Outreach |
| stage | text | Current/final stage: Lead, Qualified, Proposal, Negotiation, Won, Lost |
| lost_at_stage | text | Empty unless Lost; the stage the deal was lost at |
| lost_reason | text | Empty unless Lost; one of 6 reasons: Price too high, Chose competitor, Budget frozen, No decision — went quiet, Requirements changed, Timing — not now |
| deal_value_pkr | integer | The deal's value in PKR |
| probability_pct | integer | Stage probability: Lead 10, Qualified 25, Proposal 50, Negotiation 75, Won 100, Lost 0 |
| weighted_value_pkr | integer | `round(deal_value_pkr × probability_pct / 100)` |
| sales_cycle_days | integer | Empty for open deals; close_date − created_date for closed deals |
| is_closed | integer | 1 if Won or Lost, 0 if still open |
| is_won | integer | 1 if Won, 0 otherwise |

## The processed files — `data/processed/`

- `deals_enriched.csv` — all 156 deals as read by `src/analyze.py`.
- `stage_summary.csv` — one row per current stage (6 rows): deals, share, pipeline value, weighted value.
- `rep_summary.csv` — one row per rep (6 rows): deals, pipeline, open, closed, won, lost, win rate, revenue won, value lost, average deal sizes, average cycles.
- `monthly_summary.csv` — one row per created month (6 rows), same shape as the rep summary.
- `product_summary.csv` — one row per product line (5 rows), same shape.
- `source_summary.csv` — one row per source (4 rows), same shape.
- `lost_reason_summary.csv` — one row per lost reason (6 rows): lost deals, share of losses, value lost.

## Known quirks (read before quoting a number)

- **Win rate by created month is only meaningful for mature
  cohorts.** Deals created in May–Jun 2026 mostly have not had
  time to close yet (June: 3 of 19 closed, 0 won so far), so their
  win rates read near zero (May 5.00%, June 0.00%). Judge the win
  rate on closed deals overall (34.78%), not on the youngest
  months. The same maturity effect is why no deals were won in
  Jan–Feb by close month: a deal needs roughly 40–80 days to walk
  the stages, so the first closes land in March.
- **Small bases are noisy.** Daniyal Raza shows the highest win
  rate (55.56%) on only 9 closed deals — five wins. The
  Dashboard's lowest-win-rate row only ranks reps with 10+
  closed deals, and every rate sits next to its deal count.
- **Stage probabilities are planning weights, not measured close
  rates.** The 10/25/50/75% weights are the team's standard
  weights; the workbook shows the unweighted value next to every
  weighted value so the reader can see both.
- **The July forecast is pipeline-based, not a promise.** It is
  the weighted value of the 27 open deals expected to close in
  July 2026 (PKR 13,080,000). If those deals slip, July lands
  closer to the PKR 8,496,667 run-rate instead.
